# Krypton Templates

Item and project templates for the [Krypton Standard Toolkit](https://github.com/Krypton-Suite/Standard-Toolkit).

## Templates

- **Krypton Form** — item template that adds a `KryptonForm`.
- **Krypton Ribbon Form** — item template that adds a `KryptonForm` with a `KryptonRibbon`.
- **Krypton WinForms App** — project template for a WinForms app that starts on a `KryptonForm`.
- **Krypton Ribbon WinForms App** — project template for a WinForms app with a ribbon on the main form.

## Use

1. Install the extension and restart Visual Studio.
2. Open **Create a new project** or **Project > Add New Item**.
3. Search for **Krypton**.

Project templates reference the `Krypton.Standard.Toolkit` NuGet package.
